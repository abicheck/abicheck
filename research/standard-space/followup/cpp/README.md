## Frozen C++ client, virtual bases, RTTI and exceptions

Run `python run.py` with GXX and CLANGXX naming the GCC and Clang drivers. Linux x86-64, libstdc++, C++11, -O0. With an extracted Debian Clang package, expose its shared libraries and resource headers. This run used GCC's include directory for the missing stddef.h. Both compilers linked the system libstdc++ and runtime. Each compiler direction builds one client against its original provider. Each replacement is executed in a new process.

The VTT variant changes exactly one assembler relocation in D's VTT: the virtual V subobject uses the standalone V table during L-in-D construction. The harness checks the old relocation and the replacement slot before linking. This is an intentional synthetic ABI fault, not a source edit or a compiler defect. The VTT size, exports and hierarchy are held fixed. On all four toolchain directions only construction-time dispatch changes, 20 → 10; full-object dispatch stays 30 and both virtual-base address comparisons still agree. This witnesses a scoped V4 case under H3; neither address comparison certifies arbitrary base offsets.

Privatizing the right base independently turns the old client's dynamic crosscast from a successful R::right()=40 into null; typeid still matches D. Privatizing the exception base changes handler selection from Error to catch-all; the client's RAII destructor still runs once in each case. The cleanup observation is a compatible control, not a demonstrated missed cleanup. Each observation has its own results.csv column.

Run `check_vtt.py` with the same checkout on PYTHONPATH to replay four checker comparisons. The GCC -g pair and its stripped copies were tested with the same frozen client on the exact artifacts fed to abicheck. GNU readelf confirms a different relocation at byte offset 16 of the 56-byte _ZTT1D in both lanes. Debug info: the changed pair gives NO_CHANGE, complete assurance and zero findings while the constructor marker changes 20 → 10. Stripped: the changed pair gives UNCONFIRMED with partial assurance. Identity gives NO_CHANGE in both lanes. These receipts in checker.json identify an observable same-size VTT-content miss in this generated ELF fixture; a generic relocation diff would also need controls for address shifts that preserve the target and address point. Clang with libc++, other optimization levels and other RTTI/EH rules remain outside this experiment.
