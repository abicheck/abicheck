### Added

- **Snapshot schema v28: the ADR-063 Phase 2 `entity_id` identity carrier
  (`RecordType`/`EnumType`/`Function`/`Variable`) now persists through
  `abicheck dump`/`compare`'s JSON snapshot format**, via
  `storage/entity_id_codec.py`'s bridge onto `storage/entity_ids.py`'s
  wire-schema-v2 `EntityId` encoding (added in the previous release). A
  declaration with no resolved identity gets no key at all, and a pre-v28
  snapshot loads every carrier as `None` — both degrade cleanly, since no
  detector or report field reads this carrier yet.
