### Added

- **Directory/package `compare` reports now show what each library removed and changed, and list its added/removed public API** (#1706) — the Markdown and HTML Libraries table gains `Removed` and `Changed` columns (the member's surface removal/modification counts), and a new `## Public API changes` Markdown section lists each library's added and removed public symbols. Symbols in an internal namespace (`detail`, `impl`, `internal`, ...) or RTTI artifacts are collapsed into a stated "N internal symbols omitted" count, never dropped (ADR-067). The release JSON (schema 2.1) carries the same data on every `libraries[]` entry: `surface_removals`, `surface_modifications` and `public_api` (`added[]`, `removed[]`, `internal_omitted`). No verdict, count or exit code changes.
