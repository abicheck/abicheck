### Added

- **The call-interface evaluator models C++ member functions.** A non-static member's implicit `this` is passed as a leading pointer argument (after the hidden sret pointer when the result is returned in memory), so the `call` axis now judges a member's signature change instead of answering `unknown`, and a function turned from static to non-static (or back) reads as the register shift it is. Whether a function is a member comes from the new `Function.member_kind_fact` (free, instance, static, constructor, destructor), which the clang and castxml header backends read from the declaration's AST kind (extractor generation 85; an older reader ignores the new key). Constructors, destructors and functions without the fact (DWARF-only, the GCC plugin, older snapshots) stay `unknown`. Checked by execution on g++ and clang++ against every E13/E14 formal case as a member (formal experiment E15). No verdict or exit code changes yet.
