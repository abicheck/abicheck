### Fixed

- **Review-group gating counts follow the run's own gate** — every report's review-group gating count (Markdown "Related review groups" and "Gate contribution", the review digest's "Review:" line, the PR comment's gating-group count, and JSON `review_groups[].gating_findings`/`result_counts.gating_review_groups`) now comes from the same per-finding rule as JSON `gate_contribution` (`abicheck.policy.gate_contribution.resolved_gate_contribution`). Before, the groups counted a member's raw breaking verdict, so a severity configuration that demotes ABI breaks (`abi_breaking: warning`) still read "2 gating finding(s)" under `Gate: PASS (exit 0)`, and a `potential_breaking: error` configuration under-counted. A cross-format oracle test now checks the Markdown and digest counts against the JSON over a corpus of comparisons, gate schemes and contract states.
