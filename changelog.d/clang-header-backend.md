### Changed

- **The clang header-AST backend is an injectable extract-layer backend** — the clang run of a header dump now lives in `abicheck.extract.headers.clang.backend` (`ClangBackend`, `clang_header_dump`, `resolve_clang_langmode`) behind the `abicheck.extract.headers.backend.HeaderAstBackend` protocol (`parse(HeaderParseRequest) -> parser`), and `abicheck.dumper` dispatches through the `HEADER_AST_BACKENDS` registry. The clang process runner is a constructor argument (`ClangBackend(runner=...)`, default `dumper_clang_errors.run_clang_ast`, which checks the scan deadline and then runs clang) rather than a module name to patch. Dump output is unchanged. The private `abicheck.dumper._clang_header_dump`, `_resolve_clang_langmode` and `_log_c_to_cpp_selfheal` are removed from `dumper`; `dumper.py` shrinks by about 390 lines.
