### Fixed

- **`abi_compare`'s `used_by`/`required_symbols`-scoped-only findings and
  missing-symbol labels now evaluate correctly under `contract_evaluation`**
  — a scoped-only finding or missing-required-symbol label is itself
  ADR-049 section 4.3 item 1's strongest public-evidence tier (an explicit
  required symbol or a concrete consumer import), so it is now stamped
  `IN_CONTRACT` directly under a new `explicit_consumer_or_required_symbol_evidence`
  reason code instead of being left unstamped, or (for scoped-only
  findings) run through the header-surface evaluator, which could
  misclassify a binary-only snapshot's unresolved header surface as merely
  `unknown_unresolved`.
