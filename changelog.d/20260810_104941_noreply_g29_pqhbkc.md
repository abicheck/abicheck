### Added

- **Macro/config dependency graph (G29 Phase 5 item 2)**: a new Clang-backed
  `abicheck/buildsource/macro_graph.py` pass populates `MACRO_CONTROLS_DECL`
  (a declaration compiled only under a simple `#ifdef`/`#ifndef`/
  `#if defined`/`#if !defined` guard) and `DECL_USES_MACRO` (a declaration's
  own text references a macro defined earlier in the same file) edges on the
  optional L5 source graph, joining onto the existing `macro`/`source_decl`
  nodes only. Driven by `inline_graph_fold.fold_macro_graph` alongside the
  other Clang-backed graph passes (`dump --sources`/`--build-info`); see
  `docs/reference/source-graph-schema.md` for the schema detail.
