### Performance

- **Share request-local L2 header evidence** — scalar comparisons and release bundles now compile, decode, parse, and semantically normalize each compatible CastXML or clang context once, then copy and bind its declarations independently to every binary's real export surface.
- **Bound DPC++ AST framing work** — the multi-document selector now skips ordinary text with C-backed token searches while preserving bounded chunk storage and full-stream validation.
- **Request only the DPC++ context being analyzed** — host L2 acquisition now asks `icpx` for its SYCL host pass directly, avoiding generation of a complete unused device JSON AST; explicit device analysis retains the validated multi-document selector.
- **Carry resolved bundle metadata forward** — release bundle analysis now reuses each completed member's compact ELF and native-filename evidence instead of decoding stored snapshots or parsing live ELF binaries again solely to rebuild the final bundle graph.
