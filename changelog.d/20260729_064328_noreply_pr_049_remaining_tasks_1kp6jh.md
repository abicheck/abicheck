### Fixed

- **Leaf-mode and root-cause-mode report entries now carry contract
  evaluation fields too** — `reporter._to_json_leaf`'s `_leaf_entry` built
  its own dict for root `TYPE_*` changes instead of routing through
  `_change_to_dict`, so `--report-mode leaf` lost
  `contract_relevance`/`contract_reason_code`/`contract_assurance` on those
  findings. Separately, `--report-mode root-cause` serializes a missing-
  contract-label finding a second time into `root_causes[].findings`; a
  JSON round trip always produces an independent dict copy from the
  top-level `changes` entry, so only stamping the latter left the
  root-cause copy of the same finding unstamped.
