### Changed

- **The castxml header-AST backend is an injectable extract-layer backend** — the castxml run of a header dump now lives in `abicheck.extract.headers.castxml.backend` (`CastxmlBackend`, `castxml_dump`) behind the same `HeaderAstBackend` protocol as clang, and `abicheck.dumper.HEADER_AST_BACKENDS` holds both. The process runner and the scan-deadline check are constructor arguments (`CastxmlBackend(runner=..., check_deadline=...)`, defaults `dumper_castxml_probe.run_castxml` and `check_scan_deadline`). A failed castxml run reaches the dump's castxml-to-clang fallback as `CastxmlRunError` (a `SnapshotError` carrying the original); callers of `dumper.dump` still see the original error. `dumper_castxml.py` is now `extract`-classified (its compare-layer importers use `model.synthetic_key`). Dump output is unchanged; `dumper.py` shrinks to about 1,260 lines.
