### Fixed

- **`abicheck dump` on an unrecognizable/invalid binary now exits 64
  (usage error) again, for both ELF and PE/Mach-O** — the shared
  `execute_dump_cli_run` (`frontends/cli/dump_execute.py`) both formats'
  real dump execution now routes through was missing the
  `ValidationError` → `click.UsageError` translation the retired
  `perform_elf_dump`/`handle_non_elf_dump` call sites both had, so a bad
  input (unrecognized format, no exports matched, an invalid include
  directory, ...) silently exited 1 instead of the documented usage-error
  convention (CodeRabbit/Codex review on PR #980).
