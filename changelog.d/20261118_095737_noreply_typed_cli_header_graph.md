### Changed

- **Typed `dumper.dump()` results now include header-graph findings** — the typed API attaches the same default header-only graph the CLI attaches, through one shared owner (`workflows.dump.native.attach_default_header_graph`), so graph-derived kinds such as `var_visibility_changed` agree between the two surfaces. A vanished class specialization's `var_removed`, `type_removed` findings are replaced by the graph's answer on both surfaces. `inline_function_removed` still differs by the public-header default; that default is pending a decision.
