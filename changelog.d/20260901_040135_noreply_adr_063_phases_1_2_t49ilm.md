### Changed

- **`abicheck dump`'s real PE/Mach-O run now executes through the same
  typed `execute_dump_request` pipeline as ELF** (ADR-063 Phase 1,
  completing the PR C migration) — `handle_non_elf_dump` is retired for
  the `dump` CLI's real (non-`--dry-run`) dispatch, mirroring the earlier
  ELF migration onto `frontends/cli/dump_execute.execute_dump_cli_run`; it
  stays defined, unchanged, for its own direct unit tests. No CLI-visible
  behavior change for a valid invocation. Verified via mock-based CLI/unit
  tests only — no PE/Mach-O toolchain was available to verify a real
  end-to-end run the way the ELF migration's own test corpus does.
