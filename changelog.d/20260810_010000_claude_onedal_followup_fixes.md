### Fixed

- **Namespace-glob `**` edge cases** — a standalone `namespace: "**"` (or `"**::**"`, which collapses to it) compiled to a regex matching only the empty string or a `::`-terminated string, so an otherwise-valid catch-all suppression rule never matched an ordinary name; and the `**`-segment collapse ran on the raw pattern string, so it could also fire inside a non-globstar segment ending in `**` (e.g. `foo**::**` was corrupted to `foo**`, silently dropping the `::` boundary the fnmatch-style prefix segment still required). Both fixed: a standalone `**` now compiles to `.*`, and the collapse runs on the already-split segment list.
- **`fnmatch.translate()`'s end-of-string anchor is no longer assumed to be `\Z`** — Python 3.14 emits `\z` instead, which silently broke every multi-segment `namespace`/`entity_namespace`/`cause_namespace` suppression rule under that interpreter (each segment stayed self-anchored instead of contributing a fragment). Both anchor spellings are now accepted.
- **`diff_templates._strip_param_signature` (reused by the experimental-namespace leaf computation and the CPO detector) no longer corrupts several demangled-signature shapes**: a lookalike identifier merely ending in the substring `"operator"` (e.g. `cooperator`) was treated as a disguised call operator; a function template returning a function pointer or pointer-to-member-function (`int (*ns::f<int>(int))()` / `int (Class::*ns::f<int>(int))()`) truncated at the return-type declarator's own wrapping parenthesis instead of the function's real parameter list.
- **The composite GitHub Action's `scan` mode now forwards `--policy`/`--policy-file`/`--suppress`**, matching `compare`; previously the only way to apply a policy or suppression file to a `scan` step was the generic `extra-args` passthrough. Added a `public-header-dir` input (forwarded to `dump` and `scan`, the two modes with a `--public-header-dir` CLI flag) — previously unavailable except via `extra-args`.
- **`AbiSnapshot.index()` is now idempotent.** Several detector modules call it directly (not through the memoized `function_map`/`variable_map`/`type_by_name` accessors), so a snapshot with a genuine duplicate mangled symbol/variable/type name could log the identical "duplicate ... skipped" warning up to ~7 times per side for one compare/scan run. A second call is now a no-op.
