### Fixed

- **One finding per source-replay observation, and variables named by their qualified name.** A class-static `static constexpr int K_V` whose value changed was reported twice: once as `constant_changed` (`K_S::K_V`) and once as `var_value_changed` (`K_V`), because the variable finding named the bare leaf and no dedup key could pair the two. Variable findings now carry the qualified spelling, and the value restatement is dropped in favour of the constant. The source-replay duplicate rules move into one table, `compare/source_replay_twins.py`, with a guard that every replay kind is classified. A deleted function (`= delete`) reports `func_deleted` alone, instead of also reporting its export loss and its implied inline as separate findings. A default-argument change keeps its API-break verdict when the header copy is only compatible. No CLI flag, exit code or report field changes.
