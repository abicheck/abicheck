### Fixed

- **Header-backed PE dumps join C++ declarations to their MSVC exports** — a
  declaration castxml spells with an Itanium name (`_ZN10Calculator3addEii`) is
  now recorded as bound to the DLL's MSVC export (`?add@Calculator@@QEAAHHH@Z`)
  in its export fact, and its identity stays the castxml spelling. Before, every
  class member and namespaced function on a Windows DLL read as both
  `public_not_exported` and `exported_not_public`, so a compatible change
  reported `COMPATIBLE_WITH_RISK`. A stored PE baseline written before this
  release is joined the same way at compare time, so its members are not read
  as removed and re-added.
