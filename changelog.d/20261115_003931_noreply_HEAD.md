### Fixed

- **Header-backed PE dumps bind C++ declarations to their MSVC exports** — a
  declaration castxml spells with an Itanium name (`_ZN10Calculator3addEii`) is
  now matched to the DLL's MSVC export (`?add@Calculator@@QEAAHHH@Z`) before the
  export table is judged. Before, every class member and namespaced function on
  a Windows DLL read as both `public_not_exported` and `exported_not_public`, so
  a compatible change reported `COMPATIBLE_WITH_RISK`.
  A stored PE baseline written before this release is joined the same way at
  compare time, so it no longer reads as removed and re-added.
