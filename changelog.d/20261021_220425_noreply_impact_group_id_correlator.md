### Changed

- **`impact_assessment.impact_group_id` now follows the root-cause correlator** — it was always an alias of `root_cause_id`; it is now the `RootCauseCorrelator` group id for a finding in a multi-piece load-failure group (`FUNC_REMOVED`, `INTERNAL_SYMBOL_REQUIRED_BY_PUBLIC_API`, `CONSUMER_REQUIRED_SYMBOL_REMOVED`, including `--used-by`/`--required-symbol` siblings), and falls back to `root_cause_id` otherwise. A bare-symbol `--used-by` pair with no `caused_by_type` now shares one `impact_group_id` while `root_cause_id` stays absent. `root_cause_id`, `root_cause_display` and every report-mode grouping are unchanged. Report schema 6.3 → 6.4 (additive): `impact_group_id` may now appear without `root_cause_id`. Never affects verdict, severity or exit code.
