### Fixed

- **`--contract public` no longer withholds a real break on a record whose name another namespace shares.** When two records share a leaf name (`ns1::Cache` and `ns2::Cache`), a public signature spells only the bare `Cache *`, so the contract evaluator could not say which one the API reaches. A layout break on the reached record was recorded `UNKNOWN_UNRESOLVED` and only raised the coverage exit `1`, instead of gating as the ABI break (`4`) it is. The castxml header backend now records which record or enum each return, parameter, variable and field type resolves to (snapshot schema v54: `Function.return_type_identities_fact` and `Param`/`Variable`/`TypeField.type_identities_fact`). The public-surface walk enters the closure through those identities, and the evaluator confirms a finding against the matched record's own qualified name. A record no public signature reaches is still not confirmed, and the implicit members castxml synthesizes for every record are not counted as evidence. Snapshots without the new evidence (the clang JSON backend, DWARF, any pre-v54 baseline) behave exactly as before. A snapshot from any producer other than castxml encodes byte-for-byte as it did at schema v53.
