### Fixed

- **Coverage reasons name the precondition that failed** — `fingerprint_renames`
  was reported as "requires ELF metadata in elf_only_mode" for two ELF inputs that
  both had ELF metadata; the gate actually refused because neither side was dumped
  in `elf_only_mode`. Each refusal now states its own failed precondition. The same
  audit corrected `vtable_layout`, which blamed missing type metadata for a
  stripped side that carried types. Enforced across every format pair by
  `tests/test_support_gate_reasons.py`.
- **`abi_surface_explosion` fires only on growth** — a large export-count shrink
  (281 to 138 was the field report) was emitted under the growth kind with growth
  advice. It is no longer reported under that kind. The removed exports keep their
  own per-symbol findings. The `ChangeKind` value is unchanged.
- **Markdown review groups are folded and capped** — "Related review groups" gave
  each `std::` symbol its own multi-kilobyte section, so a NO_CHANGE report of about
  1000 symbols ran to about 650 KB of review text. Groups now collapse by namespace
  root and transition with counts and a few examples, no line exceeds 1000
  characters and the family list stops at 50, whatever the verdict. The JSON
  `review_groups` is unchanged and still holds every group.
