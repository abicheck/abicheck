### Changed

- **One subprocess supervisor for extraction-side child processes.** `abicheck.deadline.supervised_popen` is now the only place that starts a child in its own process group, registers it for SIGTERM cleanup, and tears the whole group down on any exception; `run_bounded` is built on it and gains an `env` parameter. The Bazel/Ninja query adapters, the manifest extractor runner, the Android header-abi-dumper and clang source-extractor probes, the cross-target probe, and every toolchain probe in `dumper_toolchain` (including the capped `--version` reader, which kept its own `start_new_session`/`killpg` pair) now go through it, so these probes honour an active `--timeout` budget and no longer leave grandchildren behind on timeout or interruption. A repository gate rejects a new hand-rolled process-group manager or a direct `subprocess` call in those trees (design-hardening plan, Phase 6).
