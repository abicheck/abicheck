### Added

- **Compare reports now show ADR-094's `call` axis, in shadow mode.** For every function with a `func_params_changed` or `func_return_changed` finding, `compare` asks whether a caller compiled against the old declaration still calls the new function correctly under the x86-64 System V calling convention (`compare/call_axis_shadow.py`, computed by the D8 evaluator in `compare/call_interface.py`; other platforms are `unknown`). The JSON report carries it as the optional top-level `call_axis_shadow` array (compare report schema 7.6) and the Markdown report as a "Call axis (shadow, ADR-094)" table, each entry with the axis status and reason, the existing verdict for that function, and whether the two disagree (`breaking_but_call_preserved`, e.g. a removed trailing parameter; `compatible_but_call_broken`). Advisory only: no verdict, finding, severity or exit code changes.
