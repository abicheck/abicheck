### Fixed

- **`typing.get_type_hints(CompareResult)` raised `NameError`.** `CompareResult`'s own fields (`diff`, `old_snapshot`/`new_snapshot`, `suppression`, `exit_decision`, `severity_config`) referenced six of `api_types.py`'s seven `TYPE_CHECKING`-only names directly, so any schema generator, docs tool, or other consumer introspecting this public dataclass with `typing.get_type_hints()` failed. Fixed by importing `DiffResult`/`AbiSnapshot`/`SuppressionList`/`ExitDecision`/`SeverityConfig` unconditionally; `CompileContext`/`DumpManifest` (referenced only by `InputSpec`) stay `TYPE_CHECKING`-only.
- **`service_compare_pipeline.run_compare`'s `severity_preset`/`exit_code_scheme` silently accepted positional arguments**, contradicting the function's own documented "trailing keyword-only params" contract that every parameter from `debuginfod_url` onward has claimed since PR #551. Fixed by adding the `*` separator that was missing the whole time; every real caller already passes these by keyword, so no call site changes.
