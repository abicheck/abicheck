### Fixed

- **`history` pairwise comparisons now run under the same defaults as `compare`** — each adjacent pair was scored by the raw core, so its findings lacked the public-surface growth and shrink findings (`public_surface_grew`, `public_surface_shrank`) that `compare` reports for the same two snapshots, and its verdict could diverge. Pairs now go through the same comparison entry point `compare` uses; a `history` run can therefore report surface findings it previously omitted.
