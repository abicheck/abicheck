### Changed

- **`storage/guards.py` gains a shared `strict_int` value guard**, used by
  `storage/entity_ids.py`'s ordinal and wire-schema-version fields instead
  of two independently-reinvented, call-site-local `bool`/`float`-rejecting
  checks — the same drift `guards.py`'s own consolidation already exists
  to prevent for this package's other boundary checks.
