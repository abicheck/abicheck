### Changed

- **Function signature findings now read the canonical IR (ADR-063 6B, function-signature cohort; snapshot schema v57).** `FUNC_RETURN_CHANGED`, `FUNC_PARAMS_CHANGED`, `FUNC_REF_QUAL_CHANGED` and `FUNC_VARIADIC_ADDED`/`FUNC_VARIADIC_REMOVED` are decided in the new `abicheck/compare/function_signature.py` from five facts the `SemanticIR` now carries for every function occurrence (`return_type_spelling`, `parameter_type_spellings`, `parameter_kinds`, `ref_qualifier`, `is_variadic`; `semantic_ir` document version 3, `ProjectSnapshot` section v3). The spellings are the producer's own, so verdicts are unchanged. A pre-v57 snapshot decodes the facts as not collected and the load path fills them from the snapshot's own functions (`abicheck/model/semantic_ir_function_signature.py`), so stored baselines compare exactly as before. A signature fact that is not established on a side is recorded as a declined comparison instead of passing silently.
