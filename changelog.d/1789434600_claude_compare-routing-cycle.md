### Changed

- **`CompareRequest.validate()` rejects a one-sided probe matrix.** Setting only `old_probe_matrix` or `new_probe_matrix` now fails request validation, before either input is resolved, with the same message as before. Previously the error came only after both sides had been extracted.
- **Internal: `compare`'s operand routing moved to `abicheck.frontends.cli.commands.compare_routing`.** The release fan-out dispatch (`_dispatch_release_compare`, `reject_release_incompatible_view_mode`) and inline build-source embedding (`_source_is_pack`, `_embed_inline_source_side`) left `frontends/cli/commands/compare.py`, which no longer re-exports them or `operand_diagnostics`' two helpers. The nested inline `dump` is now looked up on the running command tree. Together these remove the last import-cycle edge from `cli_compare_helpers`, so `scripts/check_ai_readiness.py`'s `IMPORT_CYCLE_ALLOWLIST` CLI cluster shrinks from 32 modules to the five that still form the registration loop. No CLI flag, exit code or report changed.
