### Changed

- **Reusable-workflow inputs renamed, with no transition period (ADR-091 R4–R7, R17, R18)** — `check-single.yml` and `check-project.yml` take the composite Action's names: `requested-depth` → `depth`, `ast-frontend` → `frontend`, `gcc-path`/`gcc-prefix` → `compiler`, `gcc-options` → `compile-options`, `contract-file` → `contract`, and `policy-file` folds into `policy` (a built-in name or a file path). `actions/check-target`'s `consumer-ast-frontend`, `consumer-gcc-path` and `consumer-gcc-options` are now `consumer-frontend`, `consumer-compiler` and `consumer-compile-options`. Each old name is still declared as a tombstone; a non-empty value fails the run before any analysis, naming its replacement. See [upgrading to 0.7](docs/start/upgrading-to-0.7.md#reusable-workflow-input-renames).
