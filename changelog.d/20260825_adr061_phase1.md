### Changed

- Implemented ADR-061 Phase 1 by moving multi-target aggregation into the
  `abicheck.workflows.aggregate` responsibility package, retaining the
  documented `abicheck.aggregate` imports as a thin compatibility facade and
  routing the CLI through the canonical workflow and report projection owners.
  The architecture gate compares no-growth debt with the PR base, so concurrent
  pre-adoption changes are not misattributed while branch-local growth still
  fails. Review hardening preserves every legacy aggregate export, freezes all
  flat root modules, validates facade expressions and package boundaries, and
  migrates remaining internal callers away from the compatibility facades.
