### Fixed

- **`run_compare`'s keyword-only `*` separator was placed too early, retroactively breaking positional calls to pre-existing parameters.** The previous fix (making `severity_preset`/`exit_code_scheme` actually keyword-only) placed the `*` before `debuginfod_url`, which made every parameter from there on (`diagnostic_comparison`, `contract_evaluation`, `include_dependencies`, `contract_mode`, `pack_policy_overrides`, `pack_internal_namespaces`, `compile_context`, `depth`) keyword-only too — a public-API break for any real caller still passing one of them positionally. Moved the separator to right before `severity_preset`: only the two newest, never-previously-released parameters are actually enforced; every older parameter keeps accepting positional binding exactly as before.
