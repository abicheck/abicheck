### Changed

- **Variable type/const findings now read the canonical IR (ADR-063 6B, variable cohort).** `VAR_TYPE_CHANGED`, `VAR_BECAME_CONST` and `VAR_LOST_CONST` are decided from each side's `SemanticIR` (`CanonicalEntity.canonical_spelling`/`cv_qualification`) through the new `abicheck/compare/variables.py`; a variable the IR cannot name is projected with the normalizer's own formula, now in `abicheck/model/semantic_ir_variable_payload.py`. Two deliberate refinements: `const` means the variable's own top-level qualifier, so `const int * const` -> `const int *` reports `VAR_LOST_CONST` instead of `VAR_TYPE_CHANGED`; and a spelling with any unresolved component (`?*`, `const ?`) or castxml's opaque `FunctionType` tag is treated as unknown rather than compared. `abicheck/extract/semantic_normalizer_artifacts.py` moved to `abicheck/model/castxml_spelling_artifacts.py`.
