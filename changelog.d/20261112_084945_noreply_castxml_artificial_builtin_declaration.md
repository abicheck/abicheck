### Fixed

- **castxml header dumps no longer record compiler-declared builtins as library functions** — when an implicit copy of an array member uses `__builtin_memcpy`, castxml declares that builtin itself (`artificial="1"`) and locates the declaration at the record in your header. The castxml backend recorded it as a public-header function, so any run with a public-header set reported `public_not_exported` for `__builtin_memcpy`. Such declarations are now skipped. Extractor generation 57; comparing a stored castxml baseline from an older generation against a new dump still lists the builtin's removal, demoted to a risk with the extractor-drift reason (re-dump the baseline to clear it).
