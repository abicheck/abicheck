### Fixed

- **A public declaration the artifact never exported no longer reports as a binary ABI break.** Since the split of `Visibility` into three independent surface facts, `compare`'s export axis deliberately keeps a promised-but-unexported declaration in the comparison population (it has to, or a regained export reports as `func_added`). Scoring its *removal* was still `func_removed`, whose whole impact is "old binaries call a symbol that no longer exists" — which cannot happen for a declaration with no exported symbol. Such a removal is now `inline_function_removed` (an API break), the kind whose own definition is exactly this shape. Surfaced by catalog case `case96_hidden_friend_removed`, whose verdict had gone `API_BREAK` → `BREAKING`, but the misclassification applied to every header-only inline, hidden friend, or version-script-hidden declaration, not only that one.
- **The Action's derived CLI option table no longer loses entries.** `action/run.sh` builds `$_CLI_VALUE_OPTIONS` by querying the installed CLI for its value-taking options, and two defects made lookups in it miss: the table was built with a leading but no trailing delimiter, so whichever option came last never matched on any platform; and on Windows, where `python.exe`'s text-mode stdout writes CRLF, every entry carried a trailing carriage return, so no option at all read as value-taking. The second silently inverted `extra-args` parsing — a literal `--write` or `--dry-run` sitting there as another option's value was misread as a real flag, suppressing this step's own report injection while a full comparison ran.
