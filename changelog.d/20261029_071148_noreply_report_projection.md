### Removed

- **The root report modules `abicheck.reporter`, `abicheck.reporter_markdown`, `abicheck.reporter_contract_blocks` and `abicheck.html_report` are retired into `abicheck/report/`** (ADR-061). `reporter.py` is now `abicheck.report.diff_report` (`to_json`, `to_stat_json`, `to_stat`), `reporter_contract_blocks.py` is `abicheck.report.contract_blocks`, and `html_report.py` is `abicheck.report.html_compute` (`generate_html_report`). `reporter_markdown.py`'s functions moved unchanged to `abicheck.report.markdown_sections` (the Markdown section `compute_*` functions), `abicheck.report.review_digest_compute` (`compute_review_digest`), `abicheck.report.root_cause_lookup` (the per-finding root-cause lookups) and `abicheck.report.release_view_filters` (the release `--view show=` filters). `to_markdown`/`to_review_digest` were already in `abicheck.report.dispatch_markdown`. The verdict labels, merge-effect phrase, severity-summary table and scoped verdict now come from one projection, `abicheck.report.outcome_summary.project_outcome`, which every pair format reads. No compatibility re-exports remain; none of these paths was documented Python API (rendering goes through `abicheck.service.render_output`). Rendered reports, report schemas, verdicts and exit codes are unchanged.
