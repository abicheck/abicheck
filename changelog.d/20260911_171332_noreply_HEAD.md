### Fixed

- **`run_compare_request` now checks its deadline before resolving
  `env_matrix_path`.** A typed `CompareRequest` with an already-expired
  `budget_s` (including `0`) previously still read and parsed
  `env_matrix_path`'s YAML file before `deadline.deadline_scope` was ever
  consulted, since entering that scope only records the deadline and never
  raises on its own. `run_compare_request` now calls `deadline.check()`
  immediately on entering the scope, before `effective_env_matrix()`, so an
  expired budget raises `DeadlineExceeded` before any file I/O.
