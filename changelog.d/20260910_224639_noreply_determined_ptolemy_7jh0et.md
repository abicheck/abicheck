### Changed

- **GitHub Action: `mode: scan` now routes to `compare`/`compare --no-baseline` unconditionally** — closing the last gap ADR-068's second 2026-09-09 amendment left open. An audit-only `mode: scan` step (no `against`/`abi-baseline`) no longer falls back to the legacy `scan` CLI; it is translated to `compare --no-baseline` like every other request shape already was. To preserve `mode: scan`'s documented default-gating behavior, the Action injects `severity-preset: default` on the translated invocation whenever the step states no preset of its own (`policy/audit_gate_exit.py`'s opt-in audit-gate exit axis, exit code `3`) — an explicit `severity-preset` (including `info-only`) is always honored instead. The Action's `verdict` output gains a new `AUDIT_GATE` value for this axis, alongside `COVERAGE_INCOMPLETE`/`SEVERITY_ERROR`, and it fails the step unconditionally like the other orthogonal axes.
