### Changed

- **`--depth binary` on header-built snapshots no longer reads as an evidence gap** — detectors that did not run only because the explicitly requested `--depth` excludes the facts they need are now summarized in one coverage line ("Detectors not applicable at --depth binary: N detectors need evidence the requested depth excludes (…)") instead of one "Detector 'x' disabled" line each. Each one is still listed in the JSON `detectors[]` with `not_evaluated: true` and the new `excluded_by_depth` field (report schema 6.5 → 6.6, additive); the doubled `disabled: disabled:` wording is gone. The summary is not a PR-comment limitation and lowers neither confidence nor analysis assurance. Public-header scoping is also no longer requested when a depth below `headers` left neither side a header surface, so such a run no longer reports a "manual review required" scoping fallback or `analysis_assurance.status: partial`; it now matches a comparison of snapshots dumped without headers. Detectors disabled for any other reason keep their own lines, and no exit code changes.
