### Changed

- **The `hybrid` header backend is a composition, not a recursive `run_dump`** — a native dump with `--header-backend hybrid` now runs one castxml leg and one clang leg of the same request through the format adapter and its post-extraction tail (`abicheck.workflows.dump.hybrid.compose_hybrid`), instead of calling `run_dump` again once per backend. Each leg keeps the same contract it had (nothing skipped at parse time, a full dependency scope, the live-source licence), so dump output is byte-identical. The metadata-attach helpers moved from the flat `abicheck/service_metadata_attach.py` (deleted) to `abicheck.extract.metadata_attach` (`try_attach_sycl_metadata`, `try_attach_python_ext_metadata`, `try_attach_numpy_capi_surface`, `try_attach_python_api_surface`).
