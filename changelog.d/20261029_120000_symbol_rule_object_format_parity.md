### Fixed

- **Symbol rules hold on Mach-O the way they already did on ELF** — three checks were written for ELF and never reached Mach-O. A Mach-O private extern (`N_PEXT` with `N_EXT`) is linked into the image but is not exported, and is no longer reported as a public export. A Mach-O export's linkage now fills the same `elf_binding` fact ELF's `.dynsym` binding fills: a weak definition reads `weak`, any other export `global`, and a removed weak export carries `symbol_binding: weak`, so a `binding: weak` suppression or reclassification applies on macOS. Archived Mach-O baselines recover it on load from their stored export table. An unread dependency side (a PE image whose decorated export names cannot establish the library's own roots) is reported as unread rather than as having no dependency-internal types.
