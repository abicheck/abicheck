### Fixed

- **Macro-spelled calling conventions on the castxml lane** — the convention is now read from the compiler's own preprocessed text at each declaration (`castxml -E -dD`), not from a final `-dM` macro table. `#undef CALL` after a declaration no longer hides a real `sysv_abi` → `ms_abi` switch, a function-like `CALL(ms_abi)` is no longer skipped, and redefining `CALL` after the declaration no longer reports a false `calling_convention_changed`. The clang lane no longer reports a spurious `func_return_changed` next to a function-like macro convention switch. The castxml AST cache schema is bumped to 5.
- **Return pointee qualifier loss across pointer levels** — `const char **f()` → `char **f()` is now `func_return_pointee_qualifier_changed` (`API_BREAK`: `const char **p = f();` stops compiling) instead of the `func_return_pointee_qualifier_removed` risk. A loss stays a risk only when the new result still converts implicitly under C++ qualification-conversion rules (e.g. `const char * const *` → `char * const *`).
- **`overload_ambiguity_introduced` checks the whole overload set** — no ambiguity is claimed when another overload takes a `std::initializer_list` at the `{}` position (it wins `f({})`), or when the old set already could not select the old overload alone (e.g. `S(int)` next to `S(const int &)` or `S(long &&)`).
