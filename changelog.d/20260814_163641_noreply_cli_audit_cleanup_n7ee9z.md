### Changed

- **`compare`/`scan --against`'s `--contract public`/`exports`/`all` now
  implies `--contract-evaluation`** instead of rejecting a lone `--contract`
  as a usage error (exit `64`): naming a domain is by itself enough to ask
  for a decision against it. `--contract-evaluation` alone (no `--contract`)
  keeps its previous domain-less behavior; it's never turned off by this.
  The typed Python API (`api_types.CompareRequest.validation_errors`,
  `service._validate_contract_mode`/`compare_snapshots`) is unaffected and
  still requires both explicitly.
