### Performance

- **Header-graph projection sidecars are read once per request** — a release comparison used to decode the same `.projection.json` sidecar once per member (48 reads for 2 distinct entries on a 28-member release, each up to 34 MiB). A successful load is now memoized inside the request's bisection scope, per sidecar, with the same per-key lock that serializes concurrent callers. Outside a scope, and in reference mode, every load still reads the disk as before, and a miss is never memoized.
