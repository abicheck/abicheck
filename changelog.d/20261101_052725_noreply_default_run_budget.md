### Changed

- **A `compare` run is never unbounded: no budget means a 2-hour default**: when you give no `--budget` (or `CompareRequest.budget_s` / the Action's `budget` input), the run now has a 2h deadline. Before, it had no deadline at all. A child process that stayed alive but never answered, for example one deadlocked on a lock it inherited at fork, used to hang the run silently. It now fails it at the deadline with exit `5`, and the error says how to set a longer budget. A comparison that legitimately needs more than 2h must now state a budget. A directory/package (release) `compare` now accepts `--budget` instead of refusing it, and an expired budget aborts the whole release with exit `5`. `compare --no-baseline` also runs under the default but cannot raise it yet. See ADR-068's 2026-11 amendment.
