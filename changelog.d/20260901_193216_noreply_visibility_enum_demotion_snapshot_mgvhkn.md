### Fixed

- **Fixed a crash comparing any stored snapshot containing a lambda/anonymous-type marker** — `qualified_name_segments._walk_rewrite_strings` (used by both `renumber_anonymous_closure_identities` and the on-load `normalize_anonymous_type_spellings_on_load` migration) demoted every `str`-subclass `Enum` field it walked past — `Function.visibility`/`Variable.visibility` (`Visibility`) included — to a plain `str`, because the rewrite callbacks it drives (e.g. `strip_anonymous_type_location`) always return a new plain string even when the content is unchanged. Any snapshot with so much as one `(lambda`/`(unnamed ` marker anywhere in `functions`/`variables`/`types`/`enums` then crashed `compare()` with `AttributeError: 'str' object has no attribute 'value'` in `diff_symbols`, regardless of whether the finding being produced touched the marker at all. `_walk_rewrite_strings` now leaves any `str` whose exact type isn't `str` (a closed-vocabulary enum member) unrewritten.
