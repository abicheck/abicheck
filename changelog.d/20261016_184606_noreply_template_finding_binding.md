### Fixed

- **Template findings now honour `binding:` selectors** — `instantiation_missing_from_binary` carries the old-side ELF linkage, and `internal_template_leaks_via_public_api` carries its removed set's aggregate linkage: `weak` only when every removed instantiation is WEAK, `None` when any binding is unknown. A consumer policy's `binding: weak` rule can now demote a WEAK-only template loss that stayed BREAKING before. The leak finding also lists every removed instantiation (`mangled`, `demangled`, `binding`) in a new, uncapped `removed_instantiations` JSON field (report schema 5.14); its `symbol` is unchanged. Note that `binding:` suppression rules can now match these two kinds too, where they previously never did. Verdicts and defaults are unchanged.
