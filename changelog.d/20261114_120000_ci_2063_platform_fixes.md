### Fixed

- **A byte-identical pair with headers on one side only is UNCONFIRMED again,
  not NO_CHANGE** — once such a pair is judged at binary depth (ADR-063's
  2026-11-14 amendment), both projected sides lacked type evidence and equal
  hashes exempted it. The header side's set-aside evidence now makes the
  effective inputs differ, so ADR-090 D1(c) does not exempt it (matrix row 17).
- **Apple arm64 data size of a record with a repeated empty base** — the
  C++11-POD tail-padding rule now uses standard-layout as C++11 defined it
  (before CWG 1813), the trait Clang lays such targets out by:
  `struct X : B, Empty {}` with `B : Empty` keeps its tail padding there.
- **castxml's clang side passes parse for the binary's C++ ABI** — the
  `noexcept`, constraint, template-default, vector-spelling and variable
  template joins now take the binary's `--target` like the primary clang
  parse, so a Windows clang no longer parses a MinGW library's headers for
  MSVC and loses every `noexcept` change.
- **CPU-dispatch roll-up on PE matches header declarations by scope** — a raw
  MSVC export is now compared with the declaration's qualified name taken from
  its own mangling (castxml spells only the bare leaf), so a removed
  header-declared ISA specialization grades BREAKING on Windows too.
