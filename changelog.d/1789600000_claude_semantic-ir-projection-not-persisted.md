### Changed

- **The function/parameter/variable `SemanticIR` facts are no longer persisted; snapshot schema is back to v56.** The ~30 function-signature, qualifier, parameter and declaration facts added to `CanonicalEntity` for the ADR-063 6B cohorts are a comparison-time projection re-derived from each snapshot's declarations, so storing them (snapshot schema v57, `semantic_ir` document version 3, `ProjectSnapshot` section v3) only created a second copy nothing read. The codec no longer writes them and refuses a document that carries one (`abicheck/storage/semantic_ir_codec.py`), the `semantic_ir` document and section are back to version 2, and the v2->v3 section migration is removed. Comparison results are unchanged. No release carried v57; a v57 snapshot written by an unreleased build is refused as newer than this one and must be re-dumped. Supersedes the v57/version-3 storage notes in the earlier function-signature and variable cut-over entries.
