### Fixed

- **A parameter type's mangling change no longer reads as a missing template instantiation** — a non-template `lib::scale(basic_vec<float, abi<8>>, float)` whose parameter type changed to `abi<16>` was reported as `instantiation_missing_from_binary` ("other instantiations of `scale` still exist"), although `scale` is not a template. A declaration's template arguments are now read from its name with the parameter list removed, so only a function whose own name carries them joins a template family. In a binary-only comparison (no header evidence), the same change is reported as one `func_params_changed` (BREAKING, the verdict it already had) instead of a removal, an addition and the misleading instantiation finding. A header-parsed comparison keeps `func_removed`, since the removed signature is part of the public contract. Real function templates and members of class templates keep the finding.
