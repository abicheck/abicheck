### Changed

- **`tu_merge.py` classified `extract` under ADR-061, via a second `model` leaf split** — `diff_symbols._is_cc_attribute`/`_CC_ATTRIBUTE_BASES` (deciding whether a contract-attribute token is a calling-convention flag) is a pure membership test with no I/O, but lived inside `diff_symbols.py`, a whole-file `compare`-classified module; `tu_merge.py` (`extract`, translation-unit fragment merging) needed it too, which is exactly the `extract -> compare` shape the previous `binary_naming.py`/`qualified_name_segments.py` splits already closed for other cases. Split it into `model/cc_attributes.py` (`CC_ATTRIBUTE_BASES`/`is_cc_attribute`); `diff_symbols.py` re-exports `_is_cc_attribute` by value for back-compat (the constant itself had no other caller, so it isn't re-exported). `tu_merge.py` now imports the canonical path directly and classifies cleanly as `extract` in `architecture/modules.yaml`. No behavior change — same function object either way, pinned by `tests/test_cc_attributes.py`.
