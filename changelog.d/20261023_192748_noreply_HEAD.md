### Changed

- **Release dependency graph covers PE/COFF and Mach-O members, not only ELF.** `libraries[].dependencies` (release schema `2.2`) and the HTML release report's graph now record PE import and delay-load DLL names, and Mach-O `LC_LOAD_DYLIB`, `LC_LOAD_WEAK_DYLIB` and `LC_REEXPORT_DYLIB` install names, matched to members by file name (PE case-insensitively) or install name. Each side names its `format`. A side whose snapshot predates a fact family marks it in `incomplete` instead of reading as complete, and a member with no format metadata carries `{"state": "not_evaluated"}` rather than an absent block, so no missing fact is drawn as "no dependencies". Snapshot schema `65` persists the new `MachoMetadata.weak_dependent_libs`; weak loads are kept apart from the hard `dependent_libs`, so existing Mach-O comparisons are unchanged.
