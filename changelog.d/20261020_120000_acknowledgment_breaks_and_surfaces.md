### Added

- **Acknowledgments reach the CLI and the Action, and an acknowledged break can stop gating** — `compare --acknowledgments FILE` and the Action's `acknowledgments` input name the records for one run (they override `.abicheck.yml`'s `acknowledgment.file`). `acknowledgment.breaks: gate|accept` (default `gate`, which keeps today's exit codes) lets `accept` drop an acknowledged break from the compatibility exit while the verdict, the report and the release recommendation still read it as a break. Only the acknowledged finding is affected; an unreviewed sibling break on the same run still exits `4`. The same setting is `CompareRequest.acknowledgment_breaks` and `checker.compare(acknowledgment_breaks=...)` in the typed API, and it is trusted only from an explicit `--config`, a `--policy` document, or a typed request. Owner: ADR-067 D5, `workflows/acknowledgment_inputs.py`.
