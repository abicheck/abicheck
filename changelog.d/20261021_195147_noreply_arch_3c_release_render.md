### Changed

- **Release report composition and temporary-directory lifetime moved out of the `compare-release` CLI** — `project_release_library_results` and the release public-surface assembly now run in `abicheck.report.release_outcome_projection.project_release_outcome`, so every release format reads one projection of the finished outcome. A `ReleaseComparePlan` owns the temporary directories it allocated for its whole `with` block, so a failure during execution or rendering removes them as well as a failure during resolution. The two `--bundle-facts-out` collision guards moved to `abicheck.frontends.cli.release_compare_request`, and `abicheck.cli_compare_release_helpers` is removed with no re-export: import from those owners instead. Output, exit codes and messages are unchanged.
