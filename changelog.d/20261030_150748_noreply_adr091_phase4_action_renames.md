### Changed

- **Action inputs renamed, with no transition period (ADR-091 R1, R2, R4–R7, R17, R18)** — the new name replaces the old one in the same release: `policy-file` folds into `policy` (a built-in name or a file path), `ast-frontend` → `frontend`, `gcc-path` → `compiler`, `gcc-options` → `compile-options`, `analysis-assurance-complete` → `require-complete`, `public-header-dir` → `public-header-dirs`, `debug-info1`/`debug-info2` → `old-debug-info`/`new-debug-info`, `devel-pkg1`/`devel-pkg2` → `old-header`/`new-header`, `old-version`/`new-version` → `old-label`/`new-label`, and `check-target`'s `requested-depth` → `depth` and `contract-file` → `contract`. Each old name is now a RETIRED input that fails the run before any analysis, with an `::error::` naming its replacement. `gcc-prefix` is removed in favour of `compiler`. See the input table in [upgrading to 0.7](docs/start/upgrading-to-0.7.md).
