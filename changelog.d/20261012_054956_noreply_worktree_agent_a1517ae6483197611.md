### Performance

- **Unparseable headers no longer cost one full parse each** — when castxml
  stops at a fatal error, the L2 exclusion loop now probes the remaining
  headers in concurrent halving waves (`ABICHECK_UNPARSEABLE_PROBE_JOBS`,
  default up to 4), so sequential rounds grow with `log(n)` rather than with
  the number of bad headers (21 rounds per tree on oneDAL). The header-graph
  clang pass memoizes a failed whole-tree parse's bisection per header tree
  and compile flags, so libraries sharing a tree bisect once instead of once
  per library. Excluded headers and graph results are unchanged.
