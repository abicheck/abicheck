### Changed

- **Source-tier changes now move their own stored generation.** The L4 source
  extractors and the L5 graph producers under `abicheck/buildsource/` get a
  third generation axis, `SOURCE_GENERATION`, separate from
  `EXTRACTOR_GENERATION`. A stored package that carries source-tier facts
  reports a `semantics_differ` drift notice when they were produced under
  different source semantics, and an L2-only package never drifts on it, so
  an L4/L5 change no longer leaves those facts unmarked (ADR-062 D2 amendment).
  Readable, never refused, and no existing package's stated generation changes.
