### Fixed

- **A header-only inline removal is reported once, not twice** — a public
  inline function removed from the headers was emitted as
  `INLINE_FUNCTION_REMOVED` by both the header tier and the L4 source replay,
  with different wording, so `compare --sources --depth source` listed one
  removal twice and counted it twice in the gating total. The header-tier
  finding (artifact-anchored, and the only one carrying the declaration's
  surface facts) is kept; the replay copy is matched to it by function name, one
  for one, and recorded as `deduplicated` in the disposition audit, so
  `detected_total` still counts both observations. A replay removal with no
  header-tier twin stays visible. The verdict and exit code are unchanged.
