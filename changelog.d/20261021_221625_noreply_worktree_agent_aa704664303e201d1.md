### Performance

- **Snapshot cache entries are written as compact JSON** — the private dump cache now serializes each entry as one fully-built, whitespace-free `json.dumps` document instead of the indented streamed writer. The encode step measured about 1.9x faster and entries about 16% smaller on a 20k-function synthetic snapshot; end-to-end gains are smaller because document build and zstd compression dominate. User-facing `abicheck dump -o` output is unchanged and stays indented.
