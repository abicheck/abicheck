### Fixed

- **`type_reachability._is_public_non_stdlib_declaration`'s `committed_roots` membership check now also matches a declaration's mangled-recovered qualified name** (Codex review, fresh evidence, follow-up to the forced-public widening fix above). `--public-symbol`/`force_public_symbols` explicitly accepts a "mangled or demangled name", but the check previously compared a forced value only against a declaration's raw `mangled` linker name and its bare, unqualified `name` (castxml/direct-clang's own spelling convention) — never against the qualified name recovered from `mangled` via Itanium/MSVC demangling. A namespaced forced value like `--public-symbol ns::api` therefore matched neither, so it silently failed to seed a stdlib direct-reference root under an active `--post-manifest`, leaving a genuine layout break `UNKNOWN_UNRESOLVED` instead of `IN_CONTRACT`. The membership check now also accepts the recovered qualified name, matching the same spelling a namespaced `--public-symbol` value is actually written in.
