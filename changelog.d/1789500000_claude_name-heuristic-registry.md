### Changed

- **Name heuristics go through one runtime registry (design-hardening Phase 5)** — every spelling-based classifier in the decision modules (enum end-sentinels, serialization tags, `detail::`/`experimental::` namespaces, reserved fields, version-stamped typedefs, ISA tokens, private version nodes, `vN` inline namespaces, and others) now registers with `abicheck.model.name_heuristics` and is catalogued by `abicheck.policy.name_heuristics`. A registered heuristic can only lower confidence or route a finding to review. A heuristic that can raise severity must name a structural fact, and it is consulted only as "name and fact". Detector verdicts are unchanged on the example catalog and the FP-rate and tier-accuracy corpora.
- **One internal-namespace matcher** — `is_internal_type`, `DEFAULT_INTERNAL_NAMESPACES` and the template-argument stripping helper now live in `abicheck.compare.internal_namespaces`. The duplicate in `policy/public_surface_closure.py` is gone. `abicheck.internal_leak` still re-exports the names.
- **`inline_body_references_renamed_member` is confirmed structurally** — the internal-namespace name now only nominates a renamed member; the finding also needs a public pimpl holder with an inline public accessor (unchanged behavior, now enforced at one point).
- **A name cannot reach a breaking finding undeclared** — lowering heuristics declare the breaking kinds they demote (`lowers_from`), and severity-raising ones the kinds they gate (`raises`). The H4 harness now follows calls from every function that consults a handle and fails on any other BREAKING/API_BREAK kind it reaches. `experimental_removed_without_replacement`, `symbol_renamed_batch`, `sycl_overload_set_removed` and `bundle_soname_skew` now each require a structural fact: no replacement in NEW, the symbol left the export table, or a DT_SONAME read on both sides. A bundle member whose SONAME was never read no longer counts toward a skew.
