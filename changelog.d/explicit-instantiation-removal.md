### Fixed

- **An explicit template instance the new header drops is now a removal** — a function or static member that the old header spelled with `extern template`, `template` instantiation, or an explicit specialization, and that the new header no longer declares, reads as `func_removed` (`var_removed` for a variable) on the clang header backend. It used to read as `func_visibility_changed` ("changed to hidden") because the primary template was still declared. The removal is the declaration the new header no longer contains, not a visibility change. Implicit instances keep the existing export-loss path, and castxml keeps it too: castxml does not record the declaration kind, so an explicit instance is judged as before until it does. The export-loss text now says the symbol "is no longer exported" instead of "hidden", since the proof is the export table, not a visibility attribute.
