### Fixed

- **The composite Action no longer misses a JSON report when `extra-args` overrides `format:` to `json`.** ADR-064's "effective-format-override" gap: a `format: text`/`markdown` step whose own `extra-args` supplies `--format json` (or the reverse) really does change what `abicheck` outputs — Click keeps only the last repeated `--format` occurrence — but `action/run.sh`'s stdout-JSON capture and its `OUTPUT_FILE` report-discovery branch both gated on the Action's own nominal `format:` input instead of the effective value, silently missing the override and leaving annotations/coverage/severity/verdict queries with no report to read. Fixed by a new `_effective_format` helper (mirroring `_extra_args_has_write_flag`'s own `extra-args`-scanning pattern) that both sites now consult instead.
