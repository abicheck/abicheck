### Fixed

- **The composite Action no longer misses a report, or fails to write one, when `extra-args` overrides `format:` in either direction.** ADR-064's "effective-format-override" gap: a `format: text`/`markdown` step whose own `extra-args` supplies `--format json` (or the reverse) really does change what `abicheck` outputs — Click keeps only the last repeated `--format` occurrence — but five of `action/run.sh`'s format-dependent decisions all gated on the Action's own nominal `format:` input instead of the effective value: three report-*discovery* sites (the stdout-JSON capture, its `OUTPUT_FILE` JSON branch, and the text-report reader `_severity_gate_exit`/`_severity_gate_categories` both read through) silently missed the override and left annotations/coverage/severity/verdict queries with no report to read, and two report-*production* decisions (compare and scan mode's own `--write json=...` sidecar injection) skipped writing a secondary JSON report because the nominal format looked already-JSON, leaving a run with no JSON report anywhere once the override took effect. Fixed by a new `_effective_format` helper (mirroring `_extra_args_has_write_flag`'s own `extra-args`-scanning pattern) that all five sites now consult instead.
