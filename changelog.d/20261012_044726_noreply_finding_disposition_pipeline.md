### Removed

- **Finding disposition, identity, redundancy and dedup have moved to their ADR-061 owners, and the old import paths are gone** — nothing a report or exit code shows changes. `abicheck.finding_identity` (and its `_atomic`/`_ctor_dtor` siblings) is now the `abicheck.compare.finding_identity` package. The pipeline runner, `PipelineContext` and the default step order moved from `abicheck.post_processing`/`post_processing_context` to `abicheck.policy.finding_disposition`, entered through `dispose_findings(changes, old, new, DispositionRules(...))`, which takes the place of `DEFAULT_PIPELINE.run(...)`'s eleven trailing keyword parameters. Every suppression application point now goes through one primitive, `dispose_by_suppression`. Root-type redundancy and deduplication moved from `abicheck.diff_filtering` to `abicheck.compare.finding_redundancy`/`finding_dedup`, and `abicheck.checker` no longer re-exports the private `diff_filtering` helpers. One internal difference: a disposition run now always keeps a disposition ledger, even when the caller passes none (ADR-067 "record before disposing").
