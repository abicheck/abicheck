### Fixed

- **C++ constructors and destructors are no longer described as vtable/typeinfo/VTT/thunk artifacts** — an added or removed undeclared export such as `_ZN3FooC1Ev` now reads "C++ ABI artifact (constructor) of a class", and each special name says what it is (`vtable`, `typeinfo`, `VTT`, `thunk`, ...). Structor detection now walks the Itanium nested name instead of matching `C1E`/`D0E` anywhere, so a function whose identifier merely contains those letters (`_ZN3foo3BC1Ev`) is no longer exempted as a class artifact, and inheriting constructors (`CI1`/`CI2`) are recognised.
