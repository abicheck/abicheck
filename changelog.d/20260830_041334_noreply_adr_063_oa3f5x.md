### Added

- **`abicheck.storage.entity_ids` gains a wire-schema-v2 bridge
  (`domain_entity_id_to_dto`/`domain_entity_id_from_dto`) for
  `model.identity.EntityId` (ADR-063 Phase 2's `ScopePath`-based domain
  identity).** `ScopePath` is encoded as an explicit list of typed segment
  records rather than a flattened `qualified_name` string, since two
  distinct `ScopePath`s (e.g. a record nested in a record vs. the same
  names nested in a namespace) can render to the identical string — a
  lossy encoding that would silently collapse two different declarations'
  identity on a save/load round trip. A version-1 migration adapter still
  loads this module's pre-existing bare `kind`/`qualified_name`/
  `discriminator` documents, as a documented best-effort reconstruction
  (every `::`-separated component becomes an untyped `Namespace` segment,
  since v1 never recorded which kind a segment was).
