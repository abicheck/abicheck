### Added

- **Class-template parameter defaults are recorded, and a header-level default change is an `API_BREAK`** (ADR-085) — the clang header backend now records each class template pattern's per-parameter default spelling as `RecordType.template_param_defaults_fact` (snapshot schema v62; a pre-v62 snapshot reads it as not recorded, never as "no defaults"). A header-only change to such a default now reports the new `TEMPLATE_PARAM_DEFAULT_CHANGED` kind (`API_BREAK`, `HEADER_OR_SOURCE_GATED`) instead of `NO_CHANGE`. An exported instantiation that already reports `DEFAULT_TEMPLATE_ARG_CHANGED` (`BREAKING`) keeps that finding alone, and the suppressed header-level relation is recorded in the disposition ledger. A template pattern whose defaults are not recorded now lowers `analysis_assurance` to `partial` instead of reading as a clean comparison. castxml does not record the defaults yet (ADR-085 D3 header scan is pending), so a castxml header-only default change still reads `NO_CHANGE`.
