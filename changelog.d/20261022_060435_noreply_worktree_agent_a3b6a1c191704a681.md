- **Action keeps its own report when `extra-args` requests another export** —
  an `extra-args: -o json=x.json` (or any other `-o`) no longer suppresses the
  Action's own `format:`/`output-file:` export, so the Markdown report the step

  caller's. Only a caller export to the *same* destination replaces ours
