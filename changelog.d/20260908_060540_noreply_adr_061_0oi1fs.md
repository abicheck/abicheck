### Changed

- **`MatrixSnapshot`/`ProbeResult` JSON I/O moved to `abicheck.workflows.findings`** —
  the documented probe-harness Python workflow
  (`docs/use/probe-harness.md`)'s `old.to_json()`/`write_matrix_snapshot`/
  `load_matrix_snapshot` no longer live on `abicheck.probe_harness`; import
  `write_matrix_snapshot`/`load_matrix_snapshot` (or
  `matrix_snapshot_to_json`/`matrix_snapshot_from_dict` for an in-memory
  round trip) from `abicheck.workflows.findings` instead (ADR-061 gap E:
  `probe_harness.py` is `compare`-classified and may not own a `storage`
  operation). `probe_harness.py` itself is unaffected — `load_probe_spec`/
  `run_probe_matrix` keep their existing import path. JSON shape and
  behavior are otherwise unchanged; there is no compatibility shim at the
  old path, so update the import.
