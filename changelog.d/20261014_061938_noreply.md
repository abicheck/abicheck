### Removed

- **`abicheck.cli_helpers_compare` is removed; its dump-only flag warning now lives in `abicheck/frontends/cli/ignored_flag_warnings.py`** — the module held a single 62-line helper, and its name was close enough to `abicheck.cli_compare_helpers` that readers were sent to the wrong file. The warning that `compare` prints when `-H`/`-I` are given alongside two snapshots (`_warn_ignored_flags`) moves unchanged to the CLI frontend module above; its text and the conditions under which it fires are the same. The other helpers its docstring still listed had already moved to their owners in `workflows/`. No CLI flag, exit code or documented Python API changes.
