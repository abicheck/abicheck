### Performance

- **Skip DWARF subtrees without decoding them when the producer emits no `DW_AT_sibling`.** clang (and so icx/icpx) never emits that attribute, so pyelftools used to fully decode -- and permanently cache -- every DIE of each function body abicheck skips, just to find the next sibling. A new per-unit index (`abicheck/extract/dwarf_subtree_index.py`) steps over those bodies from their abbreviations alone, and the calling-convention reader now decodes only a function's formal parameters. On a clang-built oneCCL 2021.15 `libccl.so` (25 MiB `.debug_info`) a headerless dump went from 80.5 s / 3.7 GB peak RSS to 50.1 s / 1.8 GB (with `ABICHECK_DWARF_LOW_MEMORY_MB=0`: 122.3 s / 529 MB to 60.5 s / 533 MB), with byte-identical snapshots. GCC output, which carries sibling links, keeps its existing path.
- **Stream the header-graph clang AST through the C JSON decoder.** `stream_top_level_decls` found element boundaries with a Python loop making two regex calls per string in the document; it now lets `JSONDecoder.raw_decode` find and decode each top-level element in one step, with the same memory bound and the same strictness about separators and truncation. On a 125 MB oneDNN AST the stream went from 8.95 s to 1.92 s (faster than a whole-document `json.load`), and a cold oneDNN 3.10.2 -> 3.11.1 `compare` from 61.7 s to 48.6 s with identical findings.
