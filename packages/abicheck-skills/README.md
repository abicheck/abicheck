# abicheck-skills

Installs [abicheck](https://github.com/abicheck/abicheck)'s Agent Skill,
**`check-abi-compatibility`**, into your coding agent's skill directory.

With the skill installed, you can ask your agent "will this change break
existing users of my library?" about a C/C++ shared-library change, a
branch, or a PR. It builds or locates both sides, runs abicheck's
deterministic compatibility analysis, and reports:

- a verdict,
- the root cause,
- which consumers are affected,
- the least costly safe fix.

## Install

```bash
# into the current project (auto-detects Claude Code, Codex/Copilot/Cursor, Gemini CLI)
npx abicheck-skills

# for every project, for one agent
npx abicheck-skills --global --agent claude
```

| `--agent`    | Installs into            | Read by                         |
|--------------|--------------------------|---------------------------------|
| `claude`     | `.claude/skills/`        | Claude Code                     |
| `agents` (aliases `codex`, `copilot`, `cursor`) | `.agents/skills/` | Codex, GitHub Copilot, Cursor |
| `gemini`     | `.gemini/skills/`        | Gemini CLI                      |
| `all`        | all three                |                                 |

The paths are relative to the project directory. With `--global` they are
relative to your home directory. Use `--path <dir>` to install into any
other skills directory.

Other commands:

```bash
npx abicheck-skills list        # what is installed where
npx abicheck-skills doctor      # is the abicheck CLI installed, and in the supported range?
npx abicheck-skills uninstall   # remove only what this tool installed
```

The installer never overwrites a directory it did not create unless you pass
`--force`. It has no dependencies.

## Requirements

The skill drives the **abicheck CLI**, which is a Python package:

```bash
pipx install abicheck      # or: pip install abicheck
```

This package's version matches the abicheck release it was built for. Each
skill declares a supported abicheck version range, and `doctor` checks that
range. Header-aware analysis needs `castxml` or clang, and a C/C++ compiler
when the skill has to build the two sides itself.

## Status

`check-abi-compatibility` is evaluated on:

- C/C++ shared libraries,
- Linux ELF,
- GCC/Clang,
- built artifacts plus public headers.

The skill can also be pointed at other platforms or toolchains. When it is,
it says so rather than reporting with the same confidence. Evaluation method
and results: `agent-evals/skills/` in the abicheck repository.

Source of truth: `skills-src/` in the abicheck repository. The files in this
package are generated by `scripts/build_npm_skill_package.py`; do not edit
them here.
